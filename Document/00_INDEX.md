## ❓ よくある質問（FAQ）

### Q1: 新しいブログ記事を公開したい

**A**: 以下の手順に従ってください：

1. **02_プロジェクト構造.md** の「開発・更新フロー」を読む
2. Markdown で記事を作成（`WebSite/blog/` フォルダ）
3. `WebSite/tools/build.js` を実行して HTML を生成
4. `WebSite/tools/translate.js` で英語版を自動生成
5. Git にコミット → GitHub にプッシュ
6. GitHub Pages で自動公開される

詳細は **02_プロジェクト構造.md** や **03_WebSite構成.md** を参照。

---

### Q2: ポートフォリオに新作品を追加したい

**A**: **03_WebSite構成.md** の「ポートフォリオ追加時」セクションで手順を確認してください。

主な手順：
1. `WebSite/portfolio/portfolio_XXXX.html` にページ作成
2. `assets/data/portfolioList.json` にメタデータ追加
3. 必要な画像を `assets/images/` に配置
4. Git にコミット → プッシュ

---

### Q3: WebSite のレイアウトを変更したい

**A**: **03_WebSite構成.md** 全体を読んでください。

特に：
- **ページテンプレート構造** - ページの基本構成
- **CSS組織** - CSS ファイルの分割管理方法
- **セクション命名規則** - ID/クラスの命名規則

---

### Q4: ビルドやデプロイが失敗している

**A**: 以下を確認してください：

1. **02_プロジェクト構造.md** でビルドプロセスを確認
2. **04_GitHub設定とスキル.md** でワークフロー設定を確認
3. GitHub Actions ジョブログを確認
4. 必要に応じて **github-actions-failure-debugging** スキルを使用

---

### Q5: プロジェクトの使用技術スタックを知りたい

**A**: **01_プロジェクト概要.md** の「使用技術」セクションを確認してください。

フロントエンド、バックエンド、インフラごとに詳しく記載されています。

---

### Q6: ファイルがどこにあるのかわからない

**A**: **02_プロジェクト構造.md** のディレクトリツリーと「ディレクトリ別説明」セクションを確認してください。

特に:
- ブログ記事 → `WebSite/blog/` または `WebSite/en/`
- CSS → `WebSite/assets/css/`
- 画像 → `WebSite/assets/images/`
- ビルドスクリプト → `WebSite/tools/`

---

### Q7: 英語版を対応させるには？

**A**: **03_WebSite構成.md** の「言語対応」セクションと **02_プロジェクト構造.md** を参照。

主な方法：
- 日本語版を `WebSite/` に配置
- 英語版を `WebSite/en/` に配置
- `translate.js` で自動翻訳
- JSONメタデータを日英両言語で管理

---

### Q8: CSS を追加・修正する場合のベストプラクティスは？

- グローバルスタイル → `base.css` または `layout.css`
- ページ固有スタイル → `page-specific.css`
- インタラクション → `post-interactions.css`
