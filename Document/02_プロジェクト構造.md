# プロジェクト構造

## ディレクトリツリー（全体構成）

```
breadmotion.github.io/
├── WebSite/                     # サイト本体
│   ├── assets/                  # 静的リソース
│   │   ├── css/                 # スタイルシート
│   │   ├── images/              # 画像ファイル
│   │   └── [ビルド済みファイル]
│   ├── blog/                    # 日本語ブログ記事
│   │   └── *.md                 # Markdown形式の記事
│   ├── en/                      # 英語ブログ記事
│   │   └── *.md                 # 翻訳記事
│   ├── portfolio/               # ポートフォリオページ群
│   │   ├── tools/               # ツール紹介
│   │   ├── games/               # ゲーム紹介
│   │   └── resources/           # 資料・その他
│   ├── partials/                # 共通部品
│   │   ├── header.html          # ヘッダー
│   │   ├── footer.html          # フッター
│   │   └── [その他共通部品]
│   ├── tools/                   # ビルド・自動化スクリプト
│   │   ├── build.js             # ビルドスクリプト
│   │   ├── translate.js         # 翻訳スクリプト
│   │   └── [その他ツール]
│   └── [生成済みHTMLファイル]
├── Document/                    # プロジェクトドキュメント
├── .github/
│   └── workflows/               # GitHub Actions設定
├── .gitignore                   # Git除外設定
├── .nojekyll                    # Jekyll無効化ファイル
├── package.json                 # Node.js依存関係
├── package-lock.json            # 依存関係ロック
├── README.md                    # プロジェクトREADME
├── sitemap.xml                  # サイトマップ（本番）
├── sitemap_test.xml             # サイトマップ（テスト用）
├── robots.txt                   # SEO設定
├── ads.txt                      # 広告配置ファイル
└── favicon.ico                  # ファビコン
```

## ディレクトリ別説明

### WebSite/
**目的**: サイト本体  
**内容**: HTML、CSS、JavaScript、ブログ記事、ポートフォリオページなど、公開されるコンテンツすべてを管理します。

### WebSite/assets/
**目的**: 静的リソース管理  
**内容**:
- `css/`: スタイルシート（レスポンシブデザイン対応）
- `images/`: ブログ画像、ポートフォリオ画像（WebP等の最適化形式含む）
- ビルド済みの最終産物（ミニファイされたCSS、最適化済み画像）

### WebSite/blog/
**目的**: 日本語ブログ記事の保存  
**内容**:
- Markdown形式（`.md`）のブログ記事
- Front Matter でメタデータを管理（タイトル、日付、カテゴリなど）
- スクリプトで自動的にHTMLに変換されます

### WebSite/en/
**目的**: 英語ブログ記事の保存  
**内容**:
- 日本語記事を翻訳した英語版
- 同じMarkdown形式で管理
- 自動翻訳スクリプトで定期生成

### WebSite/portfolio/
**目的**: 成果物（ツール、ゲーム、資料）の展示  
**構成**:
- `tools/`: 開発したツール紹介ページ
- `games/`: ゲーム紹介ページ
- `resources/`: 技術資料・その他の成果物

### WebSite/partials/
**目的**: HTMLの共通部品を管理  
**内容**:
- `header.html`: サイト全体のヘッダー（ナビゲーション含む）
- `footer.html`: サイト全体のフッター
- これらが各ページに組み込まれます

### WebSite/tools/
**目的**: ビルド・自動化スクリプト  
**主要スクリプト**:

| スクリプト | 用途 |
|----------|------|
| `build.js` | Markdown → HTMLへの変換、サイト全体の生成 |
| `translate.js` | 記事の自動翻訳（googleapis / Google Translate API利用） |
| その他 | サイトマップ生成、メタデータ処理など |

### .github/workflows/
**目的**: 継続的インテグレーション・デプロイメント（CI/CD）  
**内容**: GitHub Actions のワークフロー定義ファイル（YAMLファイル）

### ルート直下の主要ファイル

| ファイル | 説明 |
|---------|------|
| `package.json` | Node.js プロジェクト設定、依存パッケージ一覧 |
| `sitemap.xml` | 本番環境用サイトマップ（検索エンジン向け） |
| `sitemap_test.xml` | テスト用サイトマップ |
| `robots.txt` | 検索エンジン用ロボット制御ファイル |
| `ads.txt` | デジタル広告配置管理ファイル |
| `favicon.ico` | ブラウザタブ用アイコン |
| `.nojekyll` | GitHub Pages が Jekyll を使用しないよう指示 |

## ファイル処理フロー

```
Markdown記事 (blog/, en/)
    ↓
marked + gray-matter で処理
    ↓
HTML生成 (WebSite/)
    ↓
assets/ に CSS・画像統合
    ↓
sitemap.xml 自動生成
    ↓
GitHub Pages にデプロイ
    ↓
公開 https://breadmotion.github.io/WebSite/
```

## ビルド・自動化スクリプトの説明

### ブログ生成スクリプト
- Markdown → HTML変換
- Front Matter からメタデータを抽出
- 記事一覧ページの生成
- タグ・カテゴリ別の整理

### 翻訳スクリプト
- 日本語記事から英語記事を自動生成
- Google Translate API を使用
- `WebSite/en/` に自動保存

### ビルドスクリプト
- 全記事のHTML化
- スタイルシート・画像の最適化
- サイト全体の整合性チェック

### サイトマップ送信
- `sitemap.xml` の自動生成
- Google Search Console への送信
- SEO最適化

## 開発・更新フロー

1. **ブログ記事を作成**: `WebSite/blog/article.md` に Markdown で執筆
2. **スクリプト実行**: `build.js` で HTML 生成
3. **翻訳**: `translate.js` で英語版を自動生成
4. **動作確認**: ローカルでプレビュー（`sitemap_test.xml` で検証）
5. **Git コミット**: 変更内容を commit
6. **GitHub にプッシュ**: GitHub Pages に自動デプロイ（GitHub Actions）
7. **公開**: https://breadmotion.github.io/WebSite/ にて閲覧可能
