# プロジェクト概要

## プロジェクト名
**PanKUN 自作ホームページ** (breadmotion.github.io)

## 説明
PanKUN個人の技術ブログとポートフォリオを公開するホームページプロジェクト。技術記事の執筆と各種ツール・ゲーム・資料などの成果物を広く公開しています。

## 目的
- 技術ブログの公開・運用
- 開発したツールやゲーム、資料の展示
- 個人のポートフォリオサイトとしての機能
- 日本語・英語の両言語での情報提供

## 公開URL
- **メインサイト**: https://breadmotion.github.io/WebSite/
- **GitHub Repository**: https://github.com/breadmotion/breadmotion.github.io

## 主要機能

### 1. 技術ブログ
- 日本語ブログ（WebSite/blog/）
- 英語ブログ（WebSite/en/）
- Markdown形式での記事管理
- メタデータ（Front Matter）による記事管理

### 2. ポートフォリオ
- ツール、ゲーム、資料の展示（WebSite/portfolio/）
- 個別プロジェクトページの公開

### 3. 自動化スクリプト
- ブログ記事の自動生成
- 多言語対応（日本語 ⇄ 英語自動翻訳）
- サイトのビルド・デプロイメント
- サイトマップの自動生成・送信

## 使用技術

### フロントエンド
- **HTML5/CSS3**: サイト構造とスタイル
- **画像処理**: WebP形式などの最適化済み画像

### バックエンド・ビルドツール

#### JavaScript/Node.js
- **Cheerio**: HTML パース・操作
- **marked**: Markdown → HTML 変換
- **gray-matter**: Front Matter パース
- **googleapis**: Google APIs との連携

#### PHP
- **Guzzle**: HTTPクライアント
- **Google API Client**: Google APIs のPHP実装

### インフラ・デプロイメント
- **GitHub Pages**: サイトホスティング
- **GitHub Actions**: CI/CD パイプライン（推定）

## ビルド・自動化機能の概要
- ブログ記事から HTML ファイルの自動生成
- 記事の自動翻訳処理
- サイトマップ（sitemap.xml）の自動生成
- 検索エンジンへのサイトマップ送信

## プロジェクト構成

├── Document/                # ドキュメント（このファイル）
